# Excel-VBA

채널사·컨설턴트 매출의 입금 내역과 수수료를 엑셀에서 자동으로 확인·정산하고, 업체별 이력을 조회하며, 담당자별 파일을 만들어내는 작업을 자동화한다.

※사내 데이터 반출 불가, 이 저장소의 예제 데이터는 모두 가상으로 만든 값이다.

## 파일 소개
### 월 정산 (Module 시리즈)
- Module0_Helpers는 다른 Module이 함께 쓰는 공용 함수 모음이다. 가장 먼저 가져와야 한다.
- Module9_ClearCimSap은 cim, sap 시트를 헤더만 남기고 비운다.
- Module1_ImportCIM은 cim 시트의 영업담당자를 채널, 컨설턴트, 당사직원으로 구분하고 키값을 만든다.
- Module1b_ExtractToSubmission은 채널과 컨설턴트 건만 골라 제출 시트에 정리한다.
- Module7_PullUnpaidFromMissing은 전월 미지급 건을 제출 시트로 다시 불러온다.
- Module2_MatchSAP은 키값으로 sap 시트와 매칭해 매출전표, 매출전기일, 입금일자를 채운다.
- Module3b_ClassifyCommission은 전체 계약건 시트와 대조해 계약구분을 판정한다.
- Module5_AppendResolvedToContract는 확정된 계약을 전체 계약건 시트에 추가한다.
- Module6_MoveUnpaidToMissing은 미입금 건을 미지급 시트로 옮긴다.
- Module8_CheckOverdue는 연체 건을 연체확인 시트로 모은다.
- Module10_ExportSubmission은 제출 시트를 매크로 없는 새 .xlsx로 저장한다.
- Module11_VerifyLedger는 전월 제출 내역이 원장에 반영됐는지 확인한다.
- Module12_CheckMonthly는 월납 계약의 수수료가 매달 나가는지 점검한다.

### 누적 조회 (Hub 시리즈)
- Hub0_Helpers는 사업자번호, 금액, 날짜를 같은 형태로 맞추는 공용 함수 모음이다. 가장 먼저 가져와야 한다.
- Hub1_AppendSAP은 새 SAP 데이터를 SAP누적 시트에 중복 없이 추가한다.
- Hub2_Search는 조회 시트를 만들고, 업체명 또는 담당자로 거래 이력, 계약정보, 입금패턴, 미수채권을 보여준다.
- Hub4_ExportPerson은 소속과 담당자를 입력하면 그 담당자의 데이터만 담은 새 엑셀 파일을 만든다.
  
## 도입 효과
매달 수작업으로 하던 정산과 확인 작업을 매크로로 바꿔, 걸리던 시간을 크게 줄였다.

| 작업 | 기존 (수작업) | 자동화 후 |
|---|---|---|
| 월 수수료 정산 | 약 1시간 | 약 10분 |
| 전월 제출 건의 원장 반영 확인 | 약 10분 | 약 1분 |
| 월납 계약 수수료 누락 점검 | 약 10분 | 약 1분 |
| 거래처별 입금·수수료 이력 확인 | 건당 약 5분 | 약 10초 |
| 담당자별 데이터 파일 만들기 | 담당자당 약 5분 | 약 10분 |

## 전사 확대 적용

이 자동화는 계약원장만 부서별·팀별로 바꿔 넣으면 전사가 같은 방식으로 쓸 수 있다.

- 전사 입금 확인 데이터 컬럼이 동일하여 코드를 고치지 않고 계약원장 데이터만 교체하면 됨.
- 각 부서·팀은 자기 계약원장으로 같은 화면과 같은 매크로를 그대로 사용.
- 담당자별 내보내기를 쓰면 팀원마다 본인 거래처 데이터만 담긴 파일을 나눠 줄 수 있어, 다른 담당자의 데이터가 노출되지 않음.
- 팀마다 수작업 정산·확인에 쓰던 시간을 같은 방식으로 줄일 수 있음.
